What Are HTML Semantic Tags?

HTML semantic tags are elements that clearly describe the meaning and purpose of their content. They help browsers, developers, and search engines understand the structure of a webpage.

Unlike generic elements such as div and span, semantic elements provide meaningful information about the content they contain.

Some commonly used HTML semantic tags include:

  • <header> - Defines introductory content or a page header.
  • <nav> - Defines navigation links.
  • <main> - Defines the main content of a webpage.
  • <section> - Groups related content.
  • <article> - Defines independent, self-contained content.
  • <footer> - Defines footer information.

Examples of HTML Semantic Tags

The following example demonstrates how semantic tags can be used together to create a well-structured webpage. 


<header>
    <h1>My Website</h1>
</header>

<nav>
    <a href="#">Home</a>
    <a href="#">About</a>
</nav>

<main>
    <section>
        <h2>About HTML</h2>
        <p>HTML structures web content.</p>
    </section>

    <article>
        <h2>Why Learn HTML?</h2>
        <p>HTML is the foundation of webpages.</p>
    </article>
</main>

<footer>
    <p>Copyright 2026</p>
</footer>

These elements give different parts of the webpage meaningful structure, making the content easier to understand and maintain.
